Recomendador de Manejo — InfiniteStack Agent App
================================================

Modelos Random Forest e Gradient Boosted Trees (XGBoost) para prever
produtividade de cana-de-açúcar (QT_TCH_REAL) com base em dados históricos
de gold.sugarcane_productivity.

Instalação:
  plugininstall -path recomendador-manejo-1.0.0.ispz

Fonte de dados:
  gold.sugarcane_productivity (PostgreSQL)

Banco suportado: postgresql
